# 坏代码门诊（S6 场次材料）

5 个可运行脚本，**每个恰好藏 1 处 bug**（一行缺失 / 一个超参数 / 一行多余）。
全部基于 Fashion-MNIST 子集（2000 训练 / 500 验证），在 MPS 上每个跑几秒。

## 流程（每例约 25 分钟）

1. **运行**：`python bugN_xxx.py`，观察输出（loss 曲线形态、train/val acc）
2. **假设**：先写下"我认为病根是____，因为症状是____"
3. **验证**：改代码试你的假设——注意区分"验证假设的实验"与"瞎改碰运气"
4. **修复**：让脚本达到健康基线
5. **复核**：对 [ANSWERS.md](ANSWERS.md)，把根因用自己的话写进下表
