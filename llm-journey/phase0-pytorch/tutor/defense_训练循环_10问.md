# 训练循环答辩 10 问（S9 用）

> 用法同 micrograd 10 问：整文件发给 AI 考官。通过线：≥8 题讲清。

## 题目

1. `optimizer.zero_grad()` 忘了会怎样？从 `.grad` 的累加语义推导症状（loss 曲线什么形状）？
2. `loss.backward()` 忘了、但 `optimizer.step()` 还在，症状是什么？为什么 `step()` 不报错？
3. 训练循环五件套的执行顺序是：前向 → `zero_grad` → `backward` → `step` →（清零去哪了）？把 `zero_grad` 放在 step 之后、下一轮 backward 之前，错在哪？
4. `CrossEntropyLoss` 内部包含了什么运算？所以喂给它的模型输出应该是原始 logits 还是 softmax 后的概率？先 softmax 会发生什么？
5. `model.train()` 与 `model.eval()` 的区别影响哪两类层？一个带 Dropout 的模型忘了 `eval()`，验证指标会怎么变？
6. 学习率太大/太小，loss 曲线分别长什么样？你会根据曲线的哪段特征决定调大还是调小？
7. `optimizer.step()` 一句话在做什么？对应手写更新 `param -= lr * param.grad` 的哪部分？动量/Adam 相比 SGD 多了什么？
8. `loss.item()` 为什么必须转？直接 `loss_history.append(loss)` 会积累出什么问题？
9. 为什么要分训练集/验证集？"验证集准确率开始下降而训练损失仍在下降"是什么信号？该做什么？
10. 参数初始化全 0 会发生什么？为什么？对称性问题在隐藏层之间如何表现出来？

## 考官参考答案（学习者考后自查）

1. 梯度跨迭代累加 → 等效步长逐迭代增大 → loss 先正常下降、随后剧烈震荡/爆炸（NaN）。曲线特征：先降后爆。
2. 所有 `p.grad` 保持 `None`，`step()` 对 grad 为 None 的参数直接跳过（不报错），参数纹丝不动 → loss 完全平坦、恒等于初始值（多分类约 ln10 ≈ 2.30）。
3. 五件套：取数据 → 前向算 loss → `zero_grad()` → `loss.backward()` → `step()`。`zero_grad` 必须发生在**下一次 backward 之前**（本循环开头或 backward 前皆可）；放在 step 之后下轮 backward 之前的写法看似等价，但容易在"梯度累积"等刻意用法时误伤，且语义上清零属于"为下一次反向做准备"，习惯上放前。
4. 内含 log_softmax + NLL。应喂 logits；先手动 softmax 再过 CE = 双重 softmax，概率被压平，梯度极小 → 学得极慢（门诊 bug #4）。
5. 影响 Dropout（训练时随机置零）与 BatchNorm（训练用 batch 统计量、eval 用滑动平均）。忘 `eval()`：验证时 Dropout 仍在随机丢弃 → 验证准确率显著偏低且逐轮波动（门诊 bug #5）。
6. 太大：震荡/NaN；太小：缓慢单调下降、久不收敛。末端特征：末端抖动 → 减小；长平台无起色 → 增大。
7. `step()` 沿各自梯度反方向更新每个参数（带学习率）。SGD 只有这一步；动量多了"速度的历史累积"，Adam 再加梯度的一/二阶矩自适应缩放。
8. 不 `.item()` 则保留计算图引用，loss 历史拖着整张图不释放 → 内存持续增长。
9. 验证集模拟"没见过的数据"，是过拟合的探测器；该信号 = 过拟合起点 → 早停/正则/增数据。
10. 全 0 初始：同层所有神经元前向输出相同、反向梯度相同、更新后仍相同 → 永远学成同一个特征（对称性无法打破），网络有效宽度退化为 1。随机初始化打破对称。
