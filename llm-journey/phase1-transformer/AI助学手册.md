> 规则与阶段 0 完全相同（契约见 `../phase0-pytorch/tutor/prompts.md`）：
> Web 互动课程先建立直觉 → Python 实战 → 产出物落库。禁写区 AI 不准写核心代码。

## 每场操作单

### S10 · 注意力直觉（4h）
- Web 课程 c13（分词）、c14（Q/K/V）、c15（多头）读完，模拟器玩熟。
- 手算：4 个 token、d=4，手写 Q/K/V（任取数值）→ 打分 → softmax → 权重，与 Web 端对照。
- 完成标志：能不查资料回答"为什么除以 √d""因果掩码改了什么"。

### S11 · 读懂架构（4h）
- 李沐精读视频（约 1h）→ 对照《Attention Is All You Need》原文逐段过（3.2 节注意力、3.5 位置编码精读）。
- 卡壳词（LayerNorm/残差/Pre-LN）回 Web c16 或问 AI（① 号摸底卡）。

### S12–S13 · 跟敲（8h）
- Karpathy 视频分两场：前半 bigram→自注意力（S12），后半多头→Block→训练→采样（S13）。
- 跟敲纪律：逐行敲 + 每个魔法数字问一句"为什么是这个值"（64? 4 倍扩展? 0.02 的初始化 std?）。
- 训练目标：莎翁字符级、loss 收敛到 ≈1.5 以下，采样出像模像样的"伪英语"。

### S14 · ⛔禁写区重写（6h，分两场）
- 空文件重建：分词 → 嵌入 → Block×L → lm_head → 训练 → 采样。
- 阶梯提示规则照旧（L1 概念 → L2 指向 → L3 一行伪代码）。
- 完成标志：独立收敛 + 与跟敲版对比 loss 曲线形态一致；额外做一次"因果掩码开关"实验（关掉会怎样？为什么立刻学不会？）。

### S15 · 中文语料（3h）
- 任选语料（一部小说的前几章 / 自己写的日记 / 项目文档），字符级训练同一架构。
- 对比三件事写进笔记：收敛速度、生成"像话程度"、token 序列长度差异。

### S16 · 结构图 + 答辩（5h）
- 白板（或 draw.io/excalidraw）画完整结构，标注每模块张量形状（形状可先用 Web c17 追踪器校准）。
- AI 考官照图提问：Q/K/V 从哪来？为什么除 √d？掩码训练/推理差异？temperature 影响什么？
- 选做：minbpe 跟写。全部完成 → `git tag phase1-graduate`。

## 禁写区红线（与阶段 0 相同）

重写 GPT 时 AI 不得输出任何核心实现代码。你可以给它看报错和你的思路，它只许提问引导。
判断标准：`exercises/04_gpt_solo/` 的每个 commit 作者都是你。
